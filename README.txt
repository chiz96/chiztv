Recommended free hosting: GitHub Pages.

QUICK GITHUB PAGES SETUP
1. Create/sign in to a free GitHub account.
2. Create a new PUBLIC repository named: chiztv
3. Upload ALL files and the assets folder from this package.
4. Open the repository: Settings > Pages.
5. Under "Build and deployment", choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save. GitHub will give you a temporary URL such as:
   https://YOURUSERNAME.github.io/chiztv/

CONNECT CHIZTV.COM FROM GODADDY
After the GitHub Pages site is working:
1. In the GitHub repo, go to Settings > Pages.
2. Under Custom domain enter: chiztv.com
3. Save.
4. In GoDaddy DNS for chiztv.com, configure the DNS records GitHub requires.
   GitHub's current documentation should be followed when you get to this step because DNS targets can change.
5. Once DNS verifies, enable "Enforce HTTPS" in GitHub Pages.
